# Assigment3-ArrayList
This repository contains Java solutions focused on passing arrays as arguments to methods and managing file data.

Projects Overview

1.Personal Fitness Tracker: A program that reads 365 lines from steps.txt to calculate and display the average number of steps taken for each month of a non-leap year.

2.Weekly Gas Averages: This application reads 52 weekly gas prices from 1994 into an array or ArrayList. It identifies the lowest and highest prices (including week and month), calculates monthly averages, and exports a sorted list to a new file.

3.World Series Winners: A search tool that reads a chronological list of winners from 1903 to 2009. Users can input a team name to see how many championships that team won during that period.

4.PhoneBookEntry Class: A custom class with fields for names and phone numbers, including a constructor, accessors, and mutators. The program demonstrates the class by storing at least five objects in an ArrayList and displaying them via a loop.
